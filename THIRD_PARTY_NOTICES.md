## Kaikki and English Wiktionary

Structured dictionary responses are requested from [Kaikki.org](https://kaikki.org/), which publishes machine-readable data extracted with [Wiktextract](https://github.com/tatuylonen/wiktextract) from the English Wiktionary. Wiktionary entry text is made available under [CC BY-SA 4.0 and the GNU Free Documentation License](https://en.wiktionary.org/wiki/Wiktionary:Copyrights). TapGerman identifies the source and license in each dictionary card and links to the relevant source page.

## MyMemory

When selected, sentence translation uses the [MyMemory API](https://mymemory.translated.net/doc/spec.php). Requests are subject to MyMemory's terms and usage limits. Only the currently displayed subtitle sentence is sent.

## LibreTranslate

When selected, sentence translation uses a user-selected local or hosted [LibreTranslate](https://docs.libretranslate.com/) instance. LibreTranslate is AGPL-3.0 software; its API can be self-hosted. TapGerman does not bundle LibreTranslate code or models.

## AnkiConnect

Direct Anki creation uses a separately installed copy of [AnkiConnect](https://github.com/FooSoft/anki-connect), running locally inside Anki Desktop. TapGerman does not bundle the add-on.
