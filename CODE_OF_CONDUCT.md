# Code of conduct

## The short version

This project exists so people can learn languages. Be the kind of collaborator a learner would want to ask a beginner question in front of.

## Expected behaviour

- Assume good faith, and give feedback on the code rather than the person.
- Be patient with people whose first language is not the one this discussion happens in. That is, after all, the point of the project.
- Accept that maintainers may decline a change, and that "no" is sometimes about scope or the project's privacy boundaries rather than about quality.

## Unacceptable behaviour

Harassment, discriminatory or sexualised language, personal attacks, deliberate intimidation, publishing someone's private information, and sustained disruption of discussion.

## Scope

This applies in issues, pull requests, discussions, commit messages, and anywhere someone is representing the project.

## Reporting

Report a problem to the maintainer at mobashirrahman@gmail.com, or privately through GitHub. Reports are handled confidentially. Maintainers may edit or remove contributions, and may block accounts, when this document is not followed.

This is a deliberately short document. For a fuller, widely used alternative, see the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
