Watch Prime Video in the language you are learning.

TapGerman puts a clickable learning-language subtitle above your native one, defines any word without leaving the scene, and sends it to Anki with the sentence it came from.

German → English today. Chromium 111+. Not yet on the Chrome Web Store.

Three steps, then it stays out of the way

No transcript dumps, no separate study app, no pausing to type a word into a dictionary tab.

Turn on the subtitles you want

TapGerman picks up the timed-text tracks the player already loaded, so both lines stay in sync with the video clock. If a track is missing, import an SRT, VTT, or TTML file instead.

Click a word you do not know

Every word in the upper line is focusable and clickable. You get a structured entry — lemma, part of speech, gender or verb forms, IPA, examples — without leaving the scene.

Send it to Anki with its sentence

One click makes a card carrying the exact line you heard, the native translation, pronunciation audio, and a link back to the moment in the episode.

What is in it

Everything below works today in the current build.

Two languages at once

A learning-language line above a native-language line, rendered in a fullscreen-aware Shadow DOM overlay that survives the player's own UI. Size and position are yours to set.

Real dictionary entries

Definitions come from Kaikki's English Wiktionary extraction: lemma and inflected form, part of speech, noun gender and plural, verb morphology, IPA, and usage examples — not a single-word gloss.

Anki cards that grow

Cards go straight into Anki through AnkiConnect. Saving the same word in the same sense again appends the new sentence to the existing card instead of duplicating it; a genuine homonym gets its own card.

Lapse rescue

The Words tab surfaces cards you recently rated "Again" and jumps you back to the exact scene each one came from. Failed reviews turn into rewatching, not re-drilling.

Dictation mode

Press Alt+D and each line hides after it plays. Type what you heard, then see a word-by-word diff against the real subtitle. Listening practice, from material you chose.

Opt-in

Adaptive speed

Lines containing a word you previously marked hard play a little slower; everything else stays at normal speed. Difficulty follows your own vocabulary, not a fixed setting.

Opt-in

Bring your own subtitles

Import SRT, WebVTT, TTML, DFXP, or TTML2 for either line, with a per-track timing offset when a fan-made file drifts against the streamed edition.

Watching controls

Pause on hover, hide and reveal the native line, replay the current cue, and step to the previous or next line — all from the keyboard, all without touching the player's own controls.

Private by construction

No accounts, no analytics, no telemetry, no server. Subtitle tracks live in tab memory and are dropped when the episode changes; only words you explicitly save are stored.

Keyboard controls

Shortcuts match the physical key rather than the character it produces, so they work on macOS and on non-QWERTY layouts. Every one of them has a visible button too.

Alt R Replay the current learning-language cue
Alt ← → Previous / next captured cue
Alt N Hide or reveal the native line
Alt D Toggle dictation mode
Esc Close the dictionary card

Install it

TapGerman is not on the Chrome Web Store yet, so it loads unpacked. It takes about a minute.

The extension

  1. Download the latest zip from the releases page and unzip it, or clone the repository.
  2. Open chrome://extensions in Chrome, Edge, Brave, or another Chromium 111+ browser.
  3. Enable Developer mode.
  4. Choose Load unpacked and select the unzipped folder — or the repository's extension/ directory.
  5. Open a Prime Video title and start playback. Refresh the tab if it was already open.
git clone https://github.com/mobashirrahman/tapgerman.git
cd tapgerman
npm run verify   # optional: checks and tests, no dependencies to install

Anki, for one-click cards

  1. Install Anki Desktop.
  2. In Anki, open Tools → Add-ons → Get Add-ons and install AnkiConnect with code 2055492159.
  3. Restart Anki and leave it running.
  4. In the TapGerman popup, open Setup, pick a deck name, and click Test Anki connection. Approve the permission dialog Anki shows.

No Anki running? Words → Export TSV gives you a UTF-8 file you can import through Anki's normal import dialog. And to try the overlay without signing in to Prime Video, open the popup and choose Setup → Open the built-in demo.

What TapGerman does and does not touch

The extension reads timed text your browser session already has. That is the whole of its access.

Never touched

  • Video and audio bytes
  • Widevine/CDM traffic and licence requests
  • Cookies and authentication tokens
  • Which titles you watch

Stored on your machine

  • Your settings
  • Words you explicitly saved, with their sentences
  • A bounded, expiring translation cache
  • API keys, in local storage only — never synced, never sent to a content tab

Never done

  • Bulk-exporting subtitles or transcripts
  • Persisting a full subtitle track
  • Analytics, telemetry, ads, or third-party trackers
  • Selling or sharing data — there is none to sell

Where it is rough

This is a pre-1.0 build. Worth knowing before you install it.

Which languages actually work well?

The dictionary is strongest for German, which is what the project was built against. Several other Wiktionary languages work, but coverage and morphology vary. The lower line is fixed to English today because the structured glosses are English.

Will it break when Prime Video changes?

Possibly. Prime's player internals are an unsupported integration surface, so automatic track capture lives behind a small replaceable adapter. When it fails, TapGerman falls back to the subtitle currently visible on the page, or to a file you import.

Has it been tested on a real account?

It has automated fixtures and a demo player, and it has not been validated against every regional catalogue or every signed-in account. Bug reports with the title and region are genuinely useful.

What about subtitle drift?

Timing offsets are linear today, up to ±5 seconds per track. Multi-anchor drift correction for different editions and ad breaks is still planned.

Why is it called TapGerman?

A gloss is the linguistic term for an explanatory note attached to a word — exactly what a click in the subtitle line produces. The name was changed from the original development codename because it collided with two existing flashcard apps. No trademark clearance has been performed yet, so the name remains provisional until that is done.
